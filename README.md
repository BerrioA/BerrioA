### Sobre mí

Soy ingeniero de sistemas y trabajo full-stack con JavaScript y TypeScript. Me gusta construir soluciones robustas y escalables, por etapas: primero lo esencial, con entregas cortas que se pueden revisar, y después lo que sigue. Me importan el código limpio (SOLID, DRY), la seguridad de los datos y que el sistema sea fácil de mantener.

Hoy desarrollo mis propios productos y proyectos a la medida para negocios que quieren dejar de operar a mano.

### En lo que estoy trabajando

- 🦷 **KURA**: software para clínicas odontológicas (agenda, historia clínica, odontograma digital, presupuestos y consentimientos) → [kurasuite.app](https://kurasuite.app)
- ⛵ **Mi Navegar**: plataforma para clubes náuticos con reservas y cupos en tiempo real, roles y reportes.
- 🌐 **Mi portafolio**: Astro, Tailwind, GSAP y agenda conectada a Google Calendar → [BerrioA/PORTAFOLIO](https://github.com/BerrioA/PORTAFOLIO)

### Experiencia destacada

- **Sistema de Gestión de Practicantes (Gobernación de Sucre):** sistema backend para la gestión integral de practicantes, organizada por dependencias y universidades, con gestión documental y base de datos en PostgreSQL. Seguridad con JWT y Express Validator.
- **Sistema de Reservas de Salas (CECAR):** gestión de reservas de salas psicológicas para estudiantes universitarios, con autenticación JWT para distintos roles y una API RESTful.
- **Sistema de Componentes Unificado (Academia Enova):** componentes y herramientas para estandarizar procesos técnicos y acelerar entregas, con prácticas de CI/CD que redujeron errores y aceleraron los despliegues en más de un 70 %.
